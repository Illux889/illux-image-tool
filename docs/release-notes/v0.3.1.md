## What's fixed in 0.3.1

- **Black-and-white line art stays clean when it is resized.** A 1-bit image (line art, scanned drawings, barcodes) now becomes 8-bit grey when its resolution changes, as intended. Before, it was forced back to black and white, so hatching broke up, fine lines went missing and patterns appeared. This applies to TIFF files and to 1-bit images inside PDFs. A TIFF that used fax compression (CCITT Group 3/4) is now saved with LZW, which is also lossless, because fax compression can only hold black and white.
- **A cut-off JPEG goes to Error.** A JPEG that ends too early, for example after a broken upload, used to be processed as OK with a grey area where the data was missing. It now gives "the JPEG is incomplete (it ends before the image data does); the file is probably damaged or was cut off", and nothing is written to Out for it. This also applies to such a JPEG inside a PDF, when the tool changes that image. A JPEG with extra data after the image, which some phones write, is still processed.

No new settings. The Resolution rules and the AE parameters work as before.

Files: `IlluxImageTool-Setup-0.3.1.exe` (Windows) and `IlluxImageTool-0.3.1-macOS-arm64.pkg` (macOS), each with a `.sha256` file.
